# 拼一下 · 图片拼接

一个本地运行的图片拼接小工具：支持三拼、五拼、六拼，可导出 PNG 或 JPG，图片无需上传。

## 我只想使用，打开哪个文件？

双击根目录的 **[index.html](index.html)**，用 Chrome 或 Edge 打开即可。无需安装软件依赖、联网或启动服务。

选择模板 → 添加照片 → 调整画布 → 下载拼图。当前模板的图片全部添加后，下载按钮才会启用。刷新或关闭页面会清除当前编辑状态。

从 GitHub 下载时，请下载并解压整个项目，保留文件夹结构；页面需要同时读取 `assets/` 中的代码和样式。

## 目录地图：每样东西是做什么的？

采用常见静态网站项目的组织方式，按页面资源、文档、维护工具分类：

```text
图片拼接/
├─ index.html                  ← 打开工具的入口，也负责页面按钮和文字
├─ README.md                   ← 你正在看的使用说明和目录地图
├─ assets/                     ← 网页运行需要的文件
│  ├─ css/
│  │  └─ styles.css            ← 外观：颜色、大小、排版、手机适配
│  └─ js/
│     └─ app.js                ← 功能：读图片、计算拼接、预览、导出
├─ docs/                       ← 详细说明和参考资料
│  ├─ DEVELOPMENT.md           ← 开发、模板实现、检查与协作指南
│  └─ previews/                ← 五张模板布局参考图，可直接打开查看
├─ scripts/                    ← 开发维护工具，普通使用时无需打开
│  ├─ check-project.mjs        ← 检查文件引用和页面元素是否对应
│  └─ check-project.test.mjs   ← 验证上面这个检查工具是否有效
├─ .github/
│  └─ workflows/ci.yml         ← GitHub 的自动检查配置
```

你还可能看到隐藏的 `.git/` 文件夹：它保存本机的版本历史，由 Git 管理，不需要手动编辑。以点开头的项目主要供开发工具使用。

## 当前支持什么？

- 三拼：V 形斜切、平行斜切、六边形聚焦；五拼：中间梯形；六拼：中心汇聚。
- 批量选择或拖入图片、替换、调整顺序、移除和清空。
- 调整画布比例、尺寸（宽高各 100–6000 px）、间距和背景颜色。
- 居中裁切填满或完整显示，按设定的像素尺寸导出 PNG/JPG。

切换图片数量会保留已添加的照片；“清空”会清除所有位置。“重置”保留照片和模板，将画布设为 1200 × 900 px、12 px 间距、白底及居中裁切。完整设置说明见 [开发与协作指南](docs/DEVELOPMENT.md)。

## 更新怎么提交到 GitHub？

创建功能分支，修改后发起 PR（合并申请），自动检查通过并自行检查改动后，就可以合并到 `main`。当前按单人开发设置，不强制另一人批准；以后有伙伴加入时，可以再开启强制审查。具体步骤与检查命令见 [协作指南](docs/DEVELOPMENT.md)。
